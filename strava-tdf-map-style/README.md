# Strava - Restore "Vive le Tour" Map Style Option

[![Greasy Fork](https://img.shields.io/greasyfork/dt/585628-strava-restore-vive-le-tour-map-style-option?label=Strava%20-%20Restore%20%22Vive%20le%20Tour%22%20Map%20Style%20Option)][GreasyFork]


## Installation

See the [script page on Greasy Fork][GreasyFork].

## Description

During the Tour de France, Strava (both web and mobile app versions) used to add a "Vive le Tour" option as another activity map style. While this option is no longer available natively, the style is still used for activities where it was applied in the past.

This script makes the "hidden" TDF-inspired option available again, for any activity you edit.
