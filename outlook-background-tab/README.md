# Outlook - Ctrl/Cmd+Click for Background Tab

## Installation

[Install from GitHub](https://raw.githubusercontent.com/dtruebin/userscripts/main/outlook-background-tab/outlook-background-tab.user.js).

## Description

In Outlook, middle-clicking a link in an email opens it in a background tab, but <kbd>Ctrl</kbd>+click (<kbd>Cmd</kbd>+click on macOS) opens it in a foreground tab, unlike on most other sites.

This script makes <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+click open a background tab too. <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+click still opens a foreground tab.
